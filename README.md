This is a program for creating your own local AI. For the to work, you will need an LLM.
Manual:
1. Upload all files to one folder
2. Set up a server on the Studio LLM, select a neural network capable of communicating
3. Copy the server link and paste it in the file bot_engine.py in ===== НАСТРОЙКИ ===== in the LLM_STUDIO_URL line. You only need tp relpace the address
4. launch main.py. Then run app.py. Now you can chat with the bot!

P.S. The image recognition feature i under development, but you can test it by installing a suitable neural network. But then you will have to supplement the code.
